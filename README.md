# dbvm-detect
**Данный разбор реализован для демонстрации опыта практического ревёрс-инжиниринга потенциальному работодателю.**

**Название разбираемого примера - античита намеренно не раскрывается**

Техническое исследование механизмов обнаружения DBVM, взаимодействия windows-драйвера с гипервизором и обработки событий на уровне виртуализации.
## О проекте
В рамках работы исследуется механизм обнаружения гипервизора, анализируется соответствующая логика и экспериментально изучается поведение модифицированного DBVM.
Отдельное внимание уделено альтернативному способу интеграции обработчика непосредственно в код гипервизора, а также особенностям его реализации и результатам тестирования.
## Основные направления исследования
- Реверс-инжиниринг логики обнаружения гипервизора.
- Реализация альтернативного способа добавления обработчика в код гипервизора.
- Экспериментальная проверка реализации и анализ выявленных ограничений.
## Содержимое репозитория
- `Пример обхода детекта DBVM.docx` — подробный технический разбор с фрагментами кода, иллюстрациями и результатами экспериментов.
- `hv_detect/` — исходный код тестового драйвера.
- `modified_dbvm/` — модифицированные исходники DBVM, использованные в исследовании.
## Результаты
В ходе работы исследован механизм обнаружения гипервизора и реализован альтернативный способ интеграции обработчика в код DBVM. Подробное описание реализации, экспериментов и выявленных ограничений приведено в основном документе.
## Примечание
Эксперименты с гипервизорами и драйверами ядра рекомендуется проводить в контролируемой тестовой среде.

Для просмотра результатов замеров используйте DbgView.
